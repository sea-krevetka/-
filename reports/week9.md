##Добавлен виджет с хитмапом посещаемости. 

## Требование для интеграции хитмапа посещаемости с бэком

### 1. Новый API для загрузки истории посещаемости
Фронтенд ожидает endpoint:

- `GET /api/student/attendance/history`
- Параметр query: `year=2026`

### 2. Авторизация
- Запрос должен принимать заголовок:
  - `Authorization: Bearer <token>`

### 3. Формат ответа
Ожидается JSON-массив объектов:

```json
[
  { "date": "2026-04-01", "count": 1 },
  { "date": "2026-04-02", "count": 2 },
  { "date": "2026-04-05", "count": 1 }
]
```

- `date` — строка в формате `YYYY-MM-DD`
- `count` — число посещений за этот день
