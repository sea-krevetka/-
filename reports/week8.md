### 1. Функциональность

**Создание сессий посещаемости**
- Форма с параметрами: ID предмета, группы (множественный выбор), название занятия, время истечения ссылки
- Кнопка **«Создать по расписанию»** — автозаполнение из ближайшего занятия в БД
- После создания: ссылка для студентов, ID занятия, время истечения, копирование в буфер

**Статистика группы**
- Фильтры: ID группы (обяз.), ID предмета (опц.)
- Таблица: ID студента, ФИО, посещено / всего занятий, процент посещаемости
- Цветовое выделение строк (зеленый/красный)

**Графики (recharts)**
- Бар-чарт: процент посещаемости по каждому студенту
- Карточка со средним процентом по группе

### 2. Интеграция с бэкендом

| Эндпоинт | Назначение |
|----------|------------|
| `POST /api/teacher/attendance-link` | Создание сессии |
| `POST /api/teacher/attendance/group` | Статистика группы |

**Безопасность:** JWT-токен в `Authorization: Bearer`, обработка 401 → редирект на логин

**Ошибки:** Перехват HTTP-ошибок, понятные сообщения, валидация форм
