1. **Добавление функциональности**:
   - **Создание сессий посещаемости**: Форма для создания ссылок на сессии с опциональными параметрами (предмет, группы, время истечения). Добавлена кнопка "Создать по расписанию" для автоматического выбора ближайшего занятия из БД.
   - **Статистика группы**: Форма для запроса данных по группе и предмету, таблица с посещаемостью студентов (ID, ФИО, присутствия, процент).
   - **Графики**: Бар-чарт посещаемости по студентам с расчетом средней посещаемости, используя recharts.

2. **Интеграция с бэкендом**:
   - Использованы эндпоинты: `/api/teacher/attendance-link` для создания сессий и `/api/teacher/attendance/group` для статистики.
   - Обработка ошибок и аутентификация через JWT-токены.
